## Context
A one-minute long take (3 segments × 20 s, a 3×3 storyboard) in a dark science-fiction world with a large cast
(14 characters, humans and aliens). Several revise rounds on the storyboard, then paid renders; one segment came back
with a character invented from words. The project changed its own copy of `storyboard_film.py`, `SKILL.md` and
`references/formats.md` (panel `refs`, a `check` step before `videos`, a `props` step, `props` / `episode_props` in
story.json). That code is in the bundle, not in this repo.

## Lessons
| # | Theme | Lesson | Origin | Status |
|---|---|---|---|---|
| 1 | storyboard | A panel's `fix` only steers the full-size frame redrawn from that panel; the grid is drawn from the beats alone. Anything the grid must show belongs in the beat, and the grid has to be rolled again before a stale panel changes. | user correction | candidate |
| 2 | story-consistency | A fix that closes one complaint can contradict another line in the same story (a panel's fix forbids an object that the shot action and recap ask for); the render follows whichever line it reads first. When beat, fix, recap and shots disagree, which one gives is the user's call. | agent observation | candidate |
| 3 | frame-refs | A segment's only image is its first frame: a character named in the shots but standing in no frame is invented from words and comes back as some other body, while a character in the first frame comes back as their sheet. The other project gave every panel `refs` (the character and prop keys it shows), drew the keyframe from exactly those, and printed them on the page. | user correction | candidate (implemented in the bundle's `storyboard_film.py`; strongest candidate: it cost a paid render) |
| 4 | frame-refs | A free `check` before `videos` that refuses a segment whose shots name a person or object standing in none of its frames (`--force` to override) would have caught #3 before paying. | user correction | candidate (implemented in the bundle) |
| 5 | frame-refs | Honouring `refs` costs framing: a first frame built around one figure cannot also hold two more at a readable size, so a steep low angle may have to become a ground-level wide shot. Say which matters more for that shot. | agent observation | candidate |
| 6 | checks | A check run on a film made before the check existed is a gate, not a verdict: it flags what the next render would invent, not that the finished film is wrong. | agent observation | candidate |
| 7 | checks | The check reads words: a job title that repeats a tool's name (the person who clips vs the clipper) matches everywhere and over-reports. Give the tool its own name, and treat a missing prop as a softer warning than a missing person. | agent observation | candidate |
| 8 | episode-props | An object that lives only in one episode (a whistle, a letter) is re-invented on every panel without a picture; the other project added a `props` step that draws episode props once (free) from `episode_prop_blocks`. | agent observation | candidate (implemented in the bundle) |
| 9 | episode-props | Canon props a story uses are listed in story.json `props` and their pictures passed to the grid and every keyframe, so a recurring vehicle stays the same vehicle. The cause (a recurring object with no picture) is a world lesson: my-world kb 2026-10-30 #3. | user correction | adopted (2026-10-31, second world): `storyboard_film.py` passes canon prop pictures and looks |
